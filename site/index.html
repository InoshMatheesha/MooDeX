01

One list for every game you own.

Games you bought on Steam, Epic, Ubisoft or GOG, old installs from a disc, things you want to play next. They all go in one library with real cover art, a status, a rating and your notes.

  • Playing, Completed, Want to Play, Stopped
  • Search, sort by playtime, rating or last played
  • Duplicates are suggested, never merged behind your back
  • Smooth with hundreds of games: only what is on screen is drawn
02

Counted from the game, not the launcher.

Most trackers watch the program they started. With Steam or Epic that is a launcher stub that quits after a few seconds, so a four-hour evening gets logged as six seconds.

MooDeX starts the game in a Windows job object and follows every process it spawns. When a launcher hands off, MooDeX switches to watching the real game executable and keeps the session open until that game exits.

  • Exact path matching. A game is never confused with an overlay or a similar name.
  • Sleep and crashes do not inflate or lose time.
  • Every session is kept; totals are added up from them.
03

Point it at a folder. That is the setup.

Add the folders your games install into, a Steam library included. MooDeX finds each game's real executable (not the uninstaller, crash reporter or redistributable), matches the cover, and keeps watching. Install something new and it shows up on its own.

  • Play straight from the card
  • Remove a game once and it stays removed
  • Watching is event-based: no constant disk scanning
04

07

Questions

Windows says "Windows protected your PC". Is it safe?

The installer is not signed with a paid code-signing certificate yet, so SmartScreen does not recognise it. Click More info, then Run anyway. The full source is on GitHub, and the SHA-256 checksum of every download is published with each release.

Does it need anything else installed?

Only the Microsoft Edge WebView2 Runtime, which ships with Windows 11 and is already on most Windows 10 PCs. If it is missing, the installer downloads it for you.

Where is my data, and what leaves my PC?

Everything is stored in %LOCALAPPDATA%\MooDeX\v2. The only network traffic is cover downloads, catalogue lookups when you search, and the update check. There is no account and no telemetry.

Why does Discover ask for a RAWG key?

Covers and game info come from the RAWG catalogue. Paste a free personal key in Settings and it is stored in Windows Credential Manager, never in a file. Your library works fully without it.

I used MooDeX 1. Do I lose my playtime?

No. Settings has an import for your old library. You see the plan before anything is written, and your old file is backed up first.

How do updates work?

MooDeX checks GitHub Releases at startup (you can turn that off). Installing an update is one click, and the package is signature-checked before it runs.
